

# 🛒 Blinkit Sales Performance Dashboard

This project analyzes **Blinkit’s sales data** to explore performance trends, product categories, outlet types, and location-based insights using an interactive Excel dashboard.

---

## 📌 Project Overview

* Performed **data cleaning** and **find & replace** operations to prepare the dataset.
* Built an **interactive Excel dashboard** to track key performance metrics.
* Analyzed **sales trends, outlet performance, and product insights**.
* Identified **business patterns** based on outlet size, location tier, and item type.

---

## 📊 Dashboard Highlights

* **KPIs:** Total Sales, Average Sales, Number of Items, Average Rating.
* **Outlet Analysis:** Performance comparison by outlet size (High, Medium, Small) and location tier.
* **Product Insights:** Sales distribution across item categories such as Fruits & Vegetables, Snack Foods, and Dairy.
* **Fat Content Breakdown:** Comparison of Low Fat vs. Regular product performance.
* **Trend Analysis:** Outlet establishment growth across years.
* **Interactive Filters:** For outlet size, location, and item type to explore data dynamically

## 🚀 Tools & Technologies

* **Data Cleaning & Analysis:** Microsoft Excel
* **Visualization:** Excel Charts, Pivot Tables, Slicers
* **Techniques Used:** Find & Replace, Data Formatting, Conditional Formatting

---

## 📈 Key Insights

* Tier 3 outlets showed stronger sales performance compared to others.
* Fruits & Vegetables and Snack Foods were the top-performing item types.
* Medium-sized outlets generated the highest overall sales.
* Regular fat content products contributed more to total revenue.
